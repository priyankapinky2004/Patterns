## 📁 Project Structure

Each file prints a unique pattern using loops in Java:

| 📄 File Name              | 🧩 Pattern Description                   |
|---------------------------|------------------------------------------|
| `butterfly.java`          | 🦋 Butterfly Pattern                     |
| `CharPAttern.java`        | 🔠 Character-based Pyramid               |
| `DiamondPattern.java`     | 💎 Diamond Star Pattern                  |
| `FloydsTriangle.java`     | 🔢 Floyd’s Triangle                      |
| `HALfPyramid.java`        | 🧱 Half Pyramid Pattern                  |
| `HollowRectangle.java`    | ⬛ Hollow Rectangle                      |
| `HollowRhombus.java`      | 🪞 Hollow Rhombus                        |
| `INVERTEDhalf.java`       | 🔻 Inverted Half Pyramid                 |
| `InvertedRight.java`      | ◀️ Inverted Right-angled Triangle        |
| `invertedTriangle.java`   | 🔼 Inverted Triangle                     |
| `numberPyramid.java`      | 🔢 Number Pyramid                        |
| `palindromic.java`        | 🔁 Palindromic Number Pyramid           |
| `SolidRhombus.java`       | 🧊 Solid Rhombus                         |
| `traingle.java`           | ▶️ (Typo?) Right-angled Triangle         |
| `Zeroand1Triangle.java`   | ⚫⚪ 0s and 1s Triangle                   |

> 🔧 *Tip: Consider renaming `traingle.java` to `triangle.java` if it's a typo.*

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/priyankapinky2004/Patterns.git
   cd java-patterns/Patterns
   ```
2.Compile and run any file:

```
   javac butterfly.java
   java butterfly
```
